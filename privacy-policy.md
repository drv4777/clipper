# Privacy Policy for Clipper

**Last updated: July 2026**

Clipper is a browser extension that allows users to save highlighted text from webpages, along with an optional note, tags, and the source page's title and URL.

## Data Collection

Clipper does not collect, transmit, sell, or share any user data with any third party, server, or external service. All data created by using this extension — including saved clip text, notes, tags, source URLs, and page titles — is stored locally using Chrome's built-in storage API and remains on the user's own device (or synced only across that user's own Chrome profile via Chrome's built-in sync, if enabled).

## What Data Is Stored

- Text the user explicitly selects and chooses to save
- The URL and title of the page the text was selected from
- Any notes or tags the user chooses to add
- The date/time a clip was saved

This data is only ever created as a direct result of the user's own action (selecting text and choosing to save it). Clipper does not monitor browsing activity, track pages visited, or collect any data passively.

## Data Sharing

Clipper does not sell or transfer user data to any third party. Data is never used for advertising, analytics, creditworthiness determination, or any purpose beyond the extension's core function of letting users save and organize their own highlighted text.

## Data Deletion

Users can delete individual saved clips or their entire collection at any time directly within the extension (via the Delete and Delete All controls). Uninstalling the extension removes all locally stored data.

## Permissions

Clipper requests only the browser permissions necessary for its core functionality (saving, viewing, editing, exporting, and importing user-selected text). No permission is used to collect or transmit data externally.

## Contact

Questions about this policy can be directed via the extension's GitHub repository: https://github.com/drv4777/clipper-extension
